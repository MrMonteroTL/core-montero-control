# CORE TL Control Center - Starter

Local-first static prototype for GitHub Pages. This starter contains **synthetic demo data only**.

## Files
- `index.html`: application shell
- `assets/styles.css`: responsive styling
- `assets/app.js`: navigation, demo data, and browser-local storage
- `data/demo-data.json`: synthetic sample data

## Publish with GitHub Pages
1. Create a repository named `core-tl-control-center`.
2. Upload the contents of this ZIP to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save and wait for the published URL.

## Important
- Do not commit real employee data, Excel files, metrics, QA records, or credentials.
- GitHub Pages hosts only the interface. Real data should be imported locally in a later sprint.
